# Moss Rose

Rosé Pine's *syntax hues* on a **Vitesse** canvas. See the [preview](preview.html).

## Install

1. Link the theme: `ln -s "$PWD/ghostty/moss-rose" ~/.config/ghostty/themes/`
2. Set `theme = moss-rose` in the config.
3. Reload.

> Red is reserved for errors and deletions.
